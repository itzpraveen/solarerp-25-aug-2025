Place Malayalam font TTF here to enable Malayalam PDF rendering.

Recommended: NotoSansMalayalam-Regular.ttf (OFL-licensed)
- Download: https://fonts.google.com/noto/specimen/Noto+Sans+Malayalam
- Then set NEXT_PUBLIC_ML_FONT_URL to your public URL, e.g.:
  NEXT_PUBLIC_ML_FONT_URL=https://<your-domain>/fonts/NotoSansMalayalam-Regular.ttf

Alternatively, set PDF_ML_FONT_BASE64 with base64 of the TTF (large payload).
